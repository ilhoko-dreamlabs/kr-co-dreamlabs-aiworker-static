# 2단계 프로젝트 아키텍처 설계

## 목적

정적 호스팅에 적합하고 유지보수가 단순한 DreamLabs external용 웹 프로젝트를 구성한다.

## 기술 결정

| 항목 | 승인 여부 | 의사결정 여부 | 결정 | 권고 근거 | 종속성 |
|---|---|---|---|---|---|
| 프레임워크 | 승인됨 | 완료 | React | 컴포넌트 기반 UI 구성에 적합 | npm |
| 번들러 | 승인됨 | 완료 | Vite | 정적 빌드와 로컬 개발이 단순함 | Node.js |
| 언어 | 승인됨 | 완료 | TypeScript | 운영형 화면의 변경 안정성 확보 | `tsc` |
| 아이콘 | 승인됨 | 완료 | lucide-react | 일관된 버튼/상태 아이콘 | npm |
| 배포 산출물 | 승인됨 | 완료 | `dist/` | 정적 호스팅 표준 산출물 | `npm run build` |

## 디렉터리 구조

| 경로 | 역할 |
|---|---|
| `src/main.tsx` | React 앱 엔트리와 화면 구성 |
| `src/styles.css` | 전역 스타일과 반응형 레이아웃 |
| `public/docs/index.html` | 정적 문서 안내 페이지 |
| `docs/` | 단계별 설계문서와 운영 판단 기록 |
| `dist/` | 빌드 후 생성되는 정적 배포 산출물 |

## 제외 범위

| 항목 | 사유 |
|---|---|
| 백엔드 서버 | 현재 범위는 정적 프로젝트 생성 |
| 인증 연동 | 외부 공개용 상태 페이지이며 secret 비저장 원칙 적용 |
| 실시간 SSoT 동기화 | 보호 API 권한과 런북 확인 전 보류 |
