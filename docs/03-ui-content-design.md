# 3단계 UI 및 콘텐츠 설계

## 목적

외부 이해관계자가 DreamLabs AI Worker의 작업 상태, 보안 경계, 배포 판단을 빠르게 파악하도록 한다.

## 화면 구성

| 섹션 | 승인 여부 | 의사결정 여부 | 설계 | 권고안 | 종속성 |
|---|---|---|---|---|---|
| 상단 헤더 | 승인됨 | 완료 | 제품 범위와 인계 링크 표시 | 작고 명확한 내비게이션 | 콘텐츠 기준 |
| 작업 기준 요약 | 승인됨 | 완료 | SSoT 후보 신호와 정적 산출물 목표 표시 | 첫 화면에서 목적 전달 | SSoT 기준 |
| 핵심 지표 | 승인됨 | 완료 | 작업 트랙, 저장 secret, 배포 보류 조건 | 운영형 요약 | 상태 데이터 |
| 단계별 상태 표 | 승인됨 | 완료 | 항목/상태/설명/종속성 표시 | 스캔 가능한 표 | 작업계획 |
| 설계 원칙 | 승인됨 | 완료 | 보안, 반응형, 정적 호스팅 원칙 | 외부 공개용 신뢰 문구 | 정책 |
| 인계 메모 | 승인됨 | 완료 | 배포 조건과 문서 위치 안내 | 다음 담당자가 이어받기 쉬움 | 문서 |

## 문구 원칙

| 원칙 | 적용 |
|---|---|
| 과장 금지 | "완전 자동화" 등 검증되지 않은 표현 배제 |
| 보안 경계 명확화 | secret 비저장과 보호 payload 비저장을 화면과 문서에 반영 |
| 한국어 우선 | 운영자와 이해관계자가 바로 읽을 수 있는 한국어 문구 |
| 실제 상태 중심 | 마케팅 소개보다 진행 상태와 종속성 표시 |

## 접근성 및 반응형

| 항목 | 기준 |
|---|---|
| 문서 언어 | `lang="ko"` |
| 링크 라벨 | 목적을 알 수 있는 텍스트 포함 |
| 표 | 모바일에서는 가로 스크롤 허용 |
| 색상 | 흰 배경과 녹색 계열을 보조색으로 사용하고 대비 유지 |
